# 🐧 Linuxpert Apps

**Aplicativos modernos, simples e úteis para Linux**, criados por **Jonatan Luiz Gouvea**, do canal **Linuxpert**.

O **Linuxpert Apps** reúne ferramentas feitas para facilitar tarefas do dia a dia, melhorar a experiência no sistema e tornar o **Linux mais prático, acessível e amigável para todos**.

---

## ✨ Sobre o projeto

O objetivo do **Linuxpert Apps** é oferecer programas com interface visual, simples de usar e pensados para resolver problemas reais no Linux.

Aqui você encontra ferramentas para conversão de arquivos, limpeza do sistema, gerenciamento de boot, instalação de pacotes, AppImages, drivers, ajustes do sistema e muito mais.

Tudo com foco em:

- ✅ Simplicidade
- ✅ Praticidade
- ✅ Visual moderno
- ✅ Facilidade para iniciantes
- ✅ Utilidade no uso real do Linux

---

## 🚀 Principais aplicativos

| Aplicativo | Função |
|---|---|
| **Conversor de Vídeo** | Converte vídeos para formatos populares |
| **Conversor de Áudio** | Converte músicas e arquivos de áudio |
| **Conversor de Imagens** | Converte imagens para vários formatos |
| **Linuxpert System Cleaner** | Ajuda na limpeza do sistema |
| **GRUB Manager** | Facilita ajustes no GRUB |
| **UEFI Manager** | Gerencia opções relacionadas ao boot UEFI |
| **BIOS Reboot** | Reinicia diretamente para BIOS/UEFI |
| **Instalador de Pacotes .deb** | Instala pacotes Debian/Ubuntu com interface |
| **Instalador de AppImage** | Facilita o uso de aplicativos AppImage |
| **Desinstalador de Programas** | Remove programas de forma simples |
| **NVIDIA Checker** | Verifica informações da GPU NVIDIA |
| **AMD GPU Checker** | Verifica informações da GPU AMD |
| **Amplificador de Volume** | Aumenta o volume do sistema |
| **Redutor de Ruído** | Ajuda a reduzir ruídos no áudio |
| **USB Format** | Formata pendrives com facilidade |
| **Atualizador do Sistema** | Facilita atualizações do Linux |

## ⬇️ Baixar aplicativos

Você pode baixar os aplicativos do **Linuxpert Apps** pelo site oficial ou pela aba **Releases** deste repositório no GitHub.

### 🌐 Site oficial

Acesse:

**https://www.linuxpert.com.br/**

No site, escolha o aplicativo desejado e clique em **Baixar**.

### 📦 GitHub Releases

Também é possível baixar os pacotes diretamente pela aba **Releases** deste repositório.

Após baixar o pacote `.deb`, instale com:

```bash
sudo apt install ./nome-do-pacote.deb
```

Depois da instalação, procure o aplicativo no menu do sistema.

## 💙 Para quem é o Linuxpert Apps?
